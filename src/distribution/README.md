# EndsAndBends - Launch Scripts

This directory contains launcher scripts for EndsAndBends application.

## Windows

- **EAB.bat** - Launch application with default locale (English)
- **EAB_EN.bat** - Launch application in English
- **EAB_FR.bat** - Launch application in French (Lancer l'application en français)

## Linux

- **EAB.sh** - Launch application with default locale (English)
- **EAB_EN.sh** - Launch application in English
- **EAB_FR.sh** - Launch application in French (Lancer l'application en français)

## Requirements

Java 21 or higher must be installed and available in your PATH.

## Usage

### Windows
Simply double-click the desired `.bat` file, or run from command line:
```
EAB_FR.bat
```

### Linux
Make sure the script is executable (already set in the distribution), then run:
```bash
./EAB_FR.sh
```
