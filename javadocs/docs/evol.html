Guide d’évolution

 

 Ajout d’une nouvelle projection
 

On peut ajouter une nouvelle projection en implémentant une nouvelle classe spécialisée depuis la classe abstraite GeoProjection.
Après la création de la classe, il reste à l’intégrer dans l’interface utilisateur.

 

 Méthodes à surcharger

  • boolean canProject(int indexStart, double[] latitudes, double[] longitudes)

    Teste si la projection d'un tableau de point est possible pour cette projection, renvoie true ou false selon le cas.
    Par exemple pour la projection de Gauss-Krueger, cette méthode teste si les points n’ont pas un écart en latitude plus important que le seuil.

  • int getProjectableIndex(int indexStart, double[] latitudes, double[] longitudes)

    Renvoie l'indice du premier point qui sort des critères de projection, c'est à dire que cette projection peut projeter d'un seul coup tous les points entre indexStart inclu et I exclu.

  • boolean initialize(double [] latitudes, double [] longitudes)

    Initialisation de la projection, calibrage. Par exemple la projection de Gauss-Krueger, utilise cette méthode pour calculer le méridien central de la projection.

  • Point2D project(double latitude, double longitude)

    Projection d’un point.

 

 Intégration dans l’interface

La déclaration de la nouvelle classe doit se faire dans la classe OptionProjection du package ifremer.sismer.endsandbends.ui.

      // Créer un vecteur contenant les projections :
      ProjectionListProxy [] list = new ProjectionListProxy [2];
      list[0] = new ProjectionListProxy(NullProjection.class,
            StringTable.get("proj_null_name"),
            StringTable.get("proj_null_desc"));
      list[1] = new ProjectionListProxy(GaussKruegerProjection.class,
             StringTable.get("proj_gk_name"),
             StringTable.get("proj_gk_desc"));
       _ctrlListProjections.setListData(list);

Il suffit d’ajouter une ligne comme celle qui est indiquée en gras dans le code ci-dessus. Attention à changer la taille d’allocation du tableau montrée sur la seconde ligne.

 

 Traduction ou changement des textes
 

L’application utilise une table des chaînes pour la plupart des textes affichés à l’écran. Pour modifier les textes ou traduire l’application il suffit de modifier le fichier de ressources de l’application.

Le fichier de ressources se trouvent dans le répertoire :
/ifremer/sismer/endsandbends/resources, à partir de la racines des sources de l’application.
Soit, sur le CD, /EndsAndBends/Sources/ifremer/sismer/endsandbends/resources.

Après avoir modifier ce fichier, il faut recompiler le package Java EndsAndBends.jar. Cette opération ne peut s’effectuer que si un environnement de développement Java est installé.
