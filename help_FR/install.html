 Prérequis

L'application a été développée en Java et nécessite Java 21 ou supérieur.
Vous pouvez télécharger Java depuis :

  • Eclipse Temurin (recommandé)
  • Azul Zulu
  • Oracle JDK

Pour vérifier votre version de Java, tapez la commande : java -version

 

 Installation

 Sur Windows

  • Vérifier la présence de Java 21 ou supérieur en tapant la commande : java -version
    Si Java n'est pas installé ou n'est pas de la bonne version, installez une version compatible (voir Prérequis).
  • Extraire le fichier EAB_*_win.zip sur le disque dur en conservant l'arborescence.
  • L'application est prête à être lancée (voir section Lancement).

 

 Sur Linux / macOS

  • Vérifier la présence de Java 21 ou supérieur en tapant la commande : java -version
    Si Java n'est pas installé ou n'est pas de la bonne version, installez une version compatible (voir Prérequis).
  • Extraire le fichier EAB_*_linux.tar.gz : tar -xzf EAB_*_linux.tar.gz
  • Rendre les scripts exécutables : chmod +x *.sh
  • L'application est prête à être lancée (voir section Lancement).
