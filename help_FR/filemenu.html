Fonctions sur les fichiers

 

 Ouverture d’un fichier de navigation

L'application demande de saisir un nom de fichier. Les seuls fichiers lus sont les fichiers SMF de navigation. Néanmoins l'application supporte les fichiers pour lesquels les variables mbDate et mbTime sont absentes. Par contre elle ne lit que les fichiers de navigation dont les coordonnées sont des latitudes et des longitudes exprimées en degrés.

Lorsque cette fonction est appelée, l'application perd toutes les données qui étaient en mémoire auparavant.

Lorsque les données sont chargées en mémoire, l'application effectue les opérations suivantes :

  • Elle décompose la campagne en segments de navigation continus, détails
  • Elle décompose les segments qui sont trop étendus pour la projection sélectionnée, détails.
  • Elle effectue la projection des points, détails.

Comme ces opérations utilisent la projection sélectionnée, ainsi que d'autres options, les données en mémoire doivent être supprimées quand la projection est changée.

Quand le fichier est correctement chargé, l'application affiche dans la liste centrale les segments issus du fichier de navigation.

 

 Calcul automatique des modèles

Cette fonction utilise l'algorithme de base, décrit ici. Il s'agit de calculer plusieurs modèles par segment, au maximum dix.
Pour chaque segment un modèle par défaut est sélectionné. Deux critères sont pris en compte pour choisir le modèle par défaut :

  • Le premier modèle qui contient le nombre maximum de points dans un fichier résumé.
  • Le premier modèle pour lequel l'erreur est inférieure à 10 -5.

Après ce calcul, la liste des segments est mise à jour. Comme chaque segment contient plusieurs modèles, les listes déroulantes de la colonne "modèle" de chaque segment sont actives.
Le calcul effectué ne prend pas en compte le nombre de points maximum pour l'ensemble de la campagne, le nombre total de points obtenu par défaut est donc le plus souvent supérieur à la limite acceptable par un fichier résumé, sauf la liste centrale ne contient qu'un seul segment.

 

 Calcul optimisé sur la distance

Cette fonction utilise l'algorithme optimisé, décrit ici, en utilisant la distance maximale pour critère de choix du segment à optimiser.
Pour chaque segment, un seul modèle est calculé, il est nommé "optim dist".
Après ce calcul, la liste des segments est mise à jour. Comme chaque segment contient un seul modèle, les colonnes "modèle" de chaque segment sont inactives.

 

 Calcul optimisé sur l’erreur globale

Cette fonction utilise l'algorithme optimisé, décrit ici, en utilisant l'erreur pour critère de choix du segment à optimiser.
Pour chaque segment, un seul modèle est calculé, il est nommé "optim error".
Après ce calcul, la liste des segments est mise à jour. Comme chaque segment contient un seul modèle, les colonnes "modèle" de chaque segment sont inactives.

 

 Sauvegarde d’un fichier résumé

Cette fonction permet d'exporter un fichier résumé à partir des modèles sélectionnés sur chaque segment de la liste centrale. Si aucun modèle n'est sélectionné, le segment originel est utilisé.
L'application affiche un avertissement si le nombre de point total est supérieur à la limite imposée par la définition des fichiers résumé.
Puis elle demande de saisir un nom de fichier et exporte les données.
Les coordonnées écrites dans le fichier résumé sont celles qui ont été initialement lues dans le fichier de navigation, elles n'ont subi aucune transformation.
