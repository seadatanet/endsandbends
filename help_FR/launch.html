Lancement de l'application

 

L'application se lance depuis des scripts dédiés ou depuis la ligne de commande.
Elle fonctionne sous Windows, Linux et macOS.

 Windows

 Lancement par script (recommandé)

Double-cliquez sur l'un des scripts suivants :

  • EAB.bat - Lance l'application avec la langue par défaut
  • EAB_FR.bat - Lance l'application en français
  • EAB_EN.bat - Lance l'application en anglais

 Lancement manuel

Depuis l'invite de commandes (cmd ou PowerShell), dans le répertoire d'installation :

java -jar EndsAndBends.jar

Pour spécifier la langue :

java -jar EndsAndBends.jar -nl fr (français)
java -jar EndsAndBends.jar -nl en (anglais)

 Linux / macOS

 Lancement par script (recommandé)

Exécutez l'un des scripts suivants :

  • ./EAB.sh - Lance l'application avec la langue par défaut
  • ./EAB_FR.sh - Lance l'application en français
  • ./EAB_EN.sh - Lance l'application en anglais

 Lancement manuel

Depuis le terminal, dans le répertoire d'installation :

java -jar EndsAndBends.jar

Pour spécifier la langue :

java -jar EndsAndBends.jar -nl fr (français)
java -jar EndsAndBends.jar -nl en (anglais)

 Configuration Java personnalisée

Si vous souhaitez utiliser une version spécifique de Java, éditez le script de lancement (.bat ou .sh) et décommentez les lignes de configuration JAVA_HOME en adaptant le chemin vers votre installation Java.
